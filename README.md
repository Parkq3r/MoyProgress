# Мой прогресс

Русскоязычный дневник тренировок для Android 8.0 и выше. Работает локально, без регистрации. Стартовая программа рассчитана на восемь календарных недель, начинается в ближайший понедельник и использует турник и собственный вес. Тренировки можно начать вручную из раздела «Тренировки». Четвёртая неделя облегчённая, на восьмой предусмотрены контрольные подходы.

- Дневник сохраняет незавершённую тренировку, фактические повторы, время удержания, обе стороны упражнения и оценку RPE.
- Графики показывают лучший подход и суммарный объём отдельно для каждого упражнения. Объём измеряется в повторах или секундах. Для односторонних упражнений объём включает обе стороны.
- Прогрессия использует последние успешные выполнения одного шаблона тренировки, одинаковые цели, RPE и дни восстановления. Прибавка применяется к одному подходу после согласия пользователя.
- Экспорт JSON включает программы, упражнения, историю и черновик. Оформление и параметры приложения хранятся на устройстве в DataStore.

## Сборка

Требуются JDK 17, Gradle 8.13 и Android SDK 36 с Build Tools 35.0.0.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

Файл сборки находится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions загружает его в артефакт `MoyProgress-debug`. Скачайте и распакуйте архив, затем откройте APK на Android и при запросе разрешите установку из выбранного источника.

## Структура

- `domain` — модели, календарь, стартовая программа, расчёт прогресса.
- `data` — хранилище Room, DataStore и резервные копии.
- `TrainingViewModel` — операции над дневником и состояние приложения.
- `ui` — четыре раздела Jetpack Compose с Material 3 Expressive.
